# Sequence milestone: actual causes and changes

1. **Isolated strikes were authored content, not a runner limitation.** The scheduler already had a list of hit events. Neutral and old finisher had one event each. Selected normals now contain 2–3 deliberate contacts; both assists are multi-hit, specials 5/3, ultimate 8. Distinct weapon families and reaction roles avoid five damage-only copies.
2. **No actor-owned cancel API existed.** Prior normal chaining waited for every hit dispatch and erased only recovery. Added scheduler cancellation, per-move inclusive windows, one-slot direction capture, resource transaction and recovery ownership. Released projectiles persist by explicit policy. Assists do not share the main action ID.
3. **A stale movement track had been hidden by staging.** When local choreography movement became additive, copied `x=450` travel applied the approach twice. The inactive legacy offsets were removed. Staging owns approach; only intentional hop/local offsets remain.
4. **New launch timing exposed a real Chun-Li height edge.** An assist called during the launch hitstop saw height0 but upward velocity440, entered at ground level and missed its last horizontal kick. A six-tick rising prediction capped at32 pixels gives a modest entry-height correction. No strike rectangle was enlarged. It locks before commitment; sufficiently late/falling calls can still partially miss.
5. **The old meter was a hard-coded100-point single-special switch.** It now has a configurable maximum300 and transactional spend. Attack gains require actual eligible hits; specials/ultimate cannot refund from damage. Cancel bonus is once per phase, not an unlimited action engine.
6. **The old target displacement clamp could not represent wall contact.** TargetMotion now owns explicit world boundaries, velocity-driven carry, boundary-triggered rebound, one-bounce-per-combo limit and genuine recovery reset. An enabled flag alone cannot create a bounce.
7. **Cross previously mutated velocity directly while frozen.** It now deliberately stores entry motion and a bounded latest reaction for release. Global hitstop, target suspension and presentation slowdown remain separate owners.
8. **Final normal action could prematurely end the phase.** Phase resolution now checks affordable, unused meter actions before ending from exhausted normal/assist budgets. Ultimate remains usable at zero normal charges.
9. **Flat feedback hid event hierarchy.** Damage labels are bounded to seven, nearby rapid hits aggregate exact totals, heavy hits use larger warm numbers, combo damage resets on genuine recovery, and final/milestone results are explicit. Cross is target-centered; wall cue occurs only on boundary contact. Swapped-side capture exposed guide overlap with Chun-Li; guide now moves to the opposite side.

Source art and per-pose source-facing corrections remain intact. Actual rendered samples show sword/foot/arrow contact, including an effects-hidden ultimate; this is evidence for the sampled choreography, not a claim that every possible timing combination has been visually reviewed.
