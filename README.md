# TacticalComboPrototype — Roster16 intake checkpoint

Open project.godot with Godot4.4.1 and run. Compatibility renderer, GDScript only.

F1 selects main and two assists; Launch new battle applies the team. R randomizes the CPU team. Existing six characters retain their move slots. The ten additions are explicitly PARTIAL: J, Left+J, Down+J and one assist each. Up/Right normals, specials and ultimates are unavailable until authored and reviewed. No duplicate fallback moves are installed.

KOS-MOS has an enlarged animated chest discharge with aperture petals, moving filaments and a pulsing envelope. Nine explicit exposure events own damage; the visual animation never applies damage.

The supplied import kit is preserved in assets/import_kit, including original sources, research and unverified source manifests. tools/integrate_ten.py contains explicit inspected pose/timing/contact recipes and stable per-row pivots. Those bindings are prototype choreography, not verified original move data. CPU selects only available move resources. Optional per-character voice profiles are present but silent because the kit contains no audio.

Read docs/ROSTER16_HANDOFF.md for the current validation and limitations. Earlier milestone handoffs remain historical.
